## 1. Завдання до індивідуальної самостійної роботи

Розробити клієнт‑серверний веб‑застосунок на Flask, розгорнути у хмарному середовищі Render, підключити віддалену базу даних PostgreSQL та реалізувати збереження/обробку даних користувачів.

**Функціонал індивідуального завдання:** “Генератор хештегів для постів”  
- Реєстрація/логін користувача  
- Генерація хештегів по введеному тексту  
- Збереження історії генерацій у PostgreSQL (Render)  
- Профіль користувача (редагування імені + статистика)  

---

## 2. Реалізація клієнт‑серверного застосунку

### 2.1 Обране хмарне середовище
Для розгортання обрано **Render** (Web Service + PostgreSQL Database).

### 2.2 Структура проєкту
Приклад структури (з репозиторію):
- `app.py` — точка входу (WSGI)
- `hashtag_app/` — серверна логіка Flask
  - `models.py` — моделі БД (User, HashtagRequest)
  - `routes/` — маршрути: `auth.py`, `main.py`, `api.py`
  - `templates/` — HTML клієнта
  - `static/` — CSS/JS клієнта
- `requirements.txt` — залежності
- `render.yaml` — конфіг для Render Blueprint (опційно)

## 6. Висновок

У ході виконання лабораторної роботи було розроблено та розгорнуто клієнт‑серверний веб‑застосунок “Генератор хештегів” у хмарному середовищі Render.
