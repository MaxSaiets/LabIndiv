# Інструкція: Підключення Hugging Face API

## Крок 1: Реєстрація на Hugging Face

1. Перейдіть на https://huggingface.co
2. Натисніть **"Sign Up"** (або **"Log in"**, якщо вже зареєстровані)
3. Заповніть форму реєстрації (можна через Google/GitHub)

## Крок 2: Створення API токену

1. Після входу перейдіть у **Settings** (верхній правий кут → ваш профіль → Settings)
2. У лівому меню виберіть **"Access Tokens"**
3. Натисніть **"New token"**
4. Заповніть форму:
   - **Token name:** `hashtag-generator-api` (або будь-яка назва)
   - **Type:** `Read` (достатньо для публічних моделей) або `Write` (якщо потрібні приватні моделі)
5. Натисніть **"Generate token"**
6. **ВАЖЛИВО:** Скопіюйте токен одразу (він показується тільки один раз!)
   - Формат: `hf_xxxxxxxxxxxxxxxxxxxxxxxxxxxxx`

## Крок 3: Додавання токену у проєкт

### Варіант А: Локальна розробка

Створіть файл `.env` у корені проєкту:

```env
HUGGINGFACE_API_TOKEN=hf_xxxxxxxxxxxxxxxxxxxxxxxxxxxxx
SECRET_KEY=your-secret-key
DATABASE_URL=sqlite:///local.db
```

**Важливо:** Додайте `.env` у `.gitignore`, щоб не комітити токен!

### Варіант Б: Render (Production)

1. Перейдіть у ваш Web Service на Render
2. Відкрийте **Environment** → **Environment Variables**
3. Натисніть **"Add Environment Variable"**
4. Додайте:
   - **Key:** `HUGGINGFACE_API_TOKEN`
   - **Value:** `hf_xxxxxxxxxxxxxxxxxxxxxxxxxxxxx` (ваш токен)
5. Натисніть **"Save Changes"**
6. Render автоматично перезапустить сервіс

## Крок 4: Перевірка роботи

1. Запустіть застосунок
2. Введіть довгий текст поста
3. Ввімкніть "Використовувати ШІ"
4. Перевірте, що з'явилося резюме від ШІ

## Переваги використання токену

✅ **Швидша робота** — менше затримок  
✅ **Більше запитів** — вищі ліміти  
✅ **Стабільність** — менше помилок 503 (модель завантажується)  
✅ **Приватні моделі** — доступ до власних моделей  

## Якщо токен не вказано

Застосунок все одно працює, але:
- Може бути повільніше (модель завантажується при кожному запиті)
- Можливі обмеження на кількість запитів
- Можливі помилки 503 (модель ще завантажується)

## Безпека

⚠️ **НІКОЛИ не комітьте токен у Git!**

- Додайте `.env` у `.gitignore`
- Не публікуйте токен у відкритих репозиторіях
- Якщо токен потрапив у Git — негайно згенеруйте новий токен на Hugging Face

## Додаткові моделі

Можна використовувати інші моделі summarization:

- `facebook/bart-large-cnn` — для англійської (за замовчуванням)
- `facebook/mbart-large-50-many-to-many-mmt` — багатомовна
- `google/pegasus-xsum` — для коротких резюме
- Власна модель на Hugging Face

Щоб змінити модель, додайте у змінні оточення:
```
HUGGINGFACE_MODEL=facebook/mbart-large-50-many-to-many-mmt
```
